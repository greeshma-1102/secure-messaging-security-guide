# How to Evaluate a Messaging Application

Choosing a messaging application involves more than looking at the
number of features available.

Users can evaluate a messaging service by reviewing its security,
privacy, usability, and documentation.

## 1. Security Documentation

Start by looking for publicly available security documentation.

Useful documentation should explain the service's security approach
clearly and avoid unsupported or unclear claims.

## 2. Privacy Information

Review the provider's privacy documentation.

Consider:

- What information is collected?
- How is information used?
- What information is retained?
- What privacy controls are available?

## 3. Encryption Information

Look for documentation explaining how communications are protected.

Do not assume that every messaging application uses the same
encryption technology or security architecture.

## 4. Account Protection

Consider how users protect their accounts and devices.

Security can depend on both the application and the user's own
security practices.

## 5. Transparency

Public documentation can help users understand how a service works
and what security and privacy considerations apply.

## 6. Usability

Security features are most useful when users can understand and use
them correctly.

Consider whether the application provides understandable settings,
documentation, and support information.

## 7. Security Resources

As part of the evaluation process, users can review product-specific
security documentation.

For example:

[Disguise Chat Security Documentation](https://disguise.chat/security)

The linked documentation should be reviewed directly for the
provider's current information.

## Evaluation Checklist

Before choosing a messaging application, consider whether you can
find clear information about:

- Security practices
- Encryption
- Privacy
- Account protection
- Data handling
- User controls
- Security documentation
- Support resources

## Final Note

No single checklist can determine whether a messaging application is
appropriate for every user.

The best approach is to review the provider's current documentation
and consider the application's features in relation to your own
requirements.
