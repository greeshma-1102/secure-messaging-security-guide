# Messaging Security

Messaging security refers to the practices and technologies used to
protect communication from unauthorized access and unnecessary
exposure.

Security is not limited to one feature. Users should consider several
areas when evaluating a messaging application.

## Encryption

Encryption can help protect information while it is being transmitted
or stored.

When reviewing a messaging service, users should look for clear
documentation explaining how encryption is implemented and what
information is protected.

## Account Security

Account security is another important consideration.

Users should review whether a messaging service provides appropriate
account protection and whether it gives users useful security controls.

Good account-security practices may include:

- Using strong and unique credentials
- Protecting access to the device
- Keeping applications updated
- Reviewing account and privacy settings
- Avoiding suspicious links and downloads

## Device Security

The security of a messaging application also depends on the security
of the device on which it is used.

Users should keep their operating system and applications updated and
should protect devices with appropriate authentication.

## Privacy

Security and privacy are related but are not identical.

Security focuses on protecting information from unauthorized access,
while privacy also concerns how information is collected, used,
stored, and shared.

## Reviewing Security Documentation

Before choosing a messaging application, users can review the
provider's publicly available security and privacy documentation.

For an example of product-specific security documentation, see:

[Disguise Chat Security Documentation](https://disguise.chat/security)

## Conclusion

There is no single security feature that answers every security
question.

Users should review the available documentation and understand the
security and privacy controls of the messaging service they choose.
